Repository work with int variables, but if you need another type, you can open file: \textquotesingle{}\doxylink{config_8h_source}{config.\+h}\textquotesingle{} and change typedef value of stack\+\_\+data on needed.

One of the essential functions of this repository is to display every single process passed into log file.

To turn on this function delete \begin{quote}
\+\#define NO\+\_\+\+DEBUG \end{quote}


In \textquotesingle{}\doxylink{config_8h_source}{config.\+h}\textquotesingle{}
